# 🎨 Queer Resources 颜色管理系统 (Color System)

本项目的视觉设计旨在创造一个“温和、包容、极具观赏性且护眼”的用户体验。我们采用了**极光渐变色**与**毛玻璃拟态（Glassmorphism）**相结合的设计方案。

## 🌟 核心设计理念

1. **五彩斑斓白 (浅色模式)**：基于极浅的暖白底色，叠加 6 种低饱和度、极度模糊（Blur 120px）的彩虹光晕，形成流动的极光效果。
2. **五彩斑斓黑 (深色模式)**：基于深邃的纯黑底色，将彩虹光晕转化为暗调“星云”，并且**适度降低光晕亮度**，确保夜间不刺眼。
3. **卡片边界拯救计划**：深色模式下，放弃纯黑卡片，改用略带灰度的毛玻璃质感，并**强制添加微白边框**，确保每个卡片界限分明，不会融化在背景中。

## 🎨 CSS 变量定义

所有的颜色都通过 CSS 变量进行管理，切换主题时仅需修改 `data-theme` 属性。

### 1. 浅色模式（默认 `:root`）

```css
:root {
  /* 基础背景与文字 */
  --bg-base: #FDFDFD;             /* 极简暖白底色 */
  --text-primary: #1D1D1F;        /* 深邃黑灰（不用纯黑，避免刺眼） */
  --text-secondary: #515154;      /* 辅助文字 */
  --text-muted: #86868B;          /* 次要信息（如时间戳、标签） */

  /* 卡片（毛玻璃效果） */
  --card-bg: rgba(255, 255, 255, 0.7);         /* 半透明白玻璃 */
  --card-border: rgba(255, 255, 255, 0.9);     /* 提亮边缘，增加立体感 */
  --card-shadow: 0 8px 32px rgba(0, 0, 0, 0.04);
  --card-hover-shadow: 0 16px 48px rgba(0, 0, 0, 0.08);

  /* 品牌渐变与点缀色 */
  --accent-gradient: linear-gradient(135deg, #FF9A9E 0%, #FECFEF 40%, #A1C4FD 70%, #C2E9FB 100%);
  --accent-blue: #5B8DEF;
  --accent-pink: #F08BB4;
  --accent-purple: #9D7BEA;
  --accent-green: #4CAF93;

  /* 极光背景色（低饱和、低透明度） */
  --rainbow-1: rgba(255, 179, 186, 0.4); /* 浅红 */
  --rainbow-2: rgba(255, 223, 186, 0.4); /* 浅橙 */
  --rainbow-3: rgba(255, 255, 186, 0.4); /* 浅黄 */
  --rainbow-4: rgba(186, 255, 201, 0.4); /* 浅绿 */
  --rainbow-5: rgba(186, 225, 255, 0.4); /* 浅蓝 */
  --rainbow-6: rgba(232, 186, 255, 0.4); /* 浅紫 */
}
```

### 2. 深色模式（`[data-theme="dark"]`）

```css
[data-theme="dark"] {
  /* 基础背景与文字 */
  --bg-base: #0A0A0C;             /* 深邃黑（夜空黑，非纯黑） */
  --text-primary: #F5F5F7;        /* 极浅的灰白（避免纯白引发光晕） */
  --text-secondary: #A1A1A6;
  --text-muted: #6E6E73;

  /* 卡片（提升明度差 + 微白边框，拯救深色融入背景的问题） */
  --card-bg: rgba(30, 30, 35, 0.6);            /* 深空灰玻璃，比背景亮 */
  --card-border: rgba(255, 255, 255, 0.08);    /* ⚠️ 核心：微白边框勾勒界限 */
  --card-shadow: 0 8px 32px rgba(0, 0, 0, 0.5);
  --card-hover-shadow: 0 16px 48px rgba(0, 0, 0, 0.7), 0 0 0 1px rgba(255, 255, 255, 0.15);

  /* 品牌渐变与点缀色（提亮以适应深色背景） */
  --accent-blue: #7AA5FF;
  --accent-pink: #FF9EC5;
  --accent-purple: #B898FF;
  --accent-green: #5ED8B5;

  /* 暗调星云极光（降低亮度与透明度，深邃而模糊） */
  --rainbow-1: rgba(255, 94, 126, 0.15);  /* 暗红 */
  --rainbow-2: rgba(255, 158, 94, 0.15);  /* 暗橙 */
  --rainbow-3: rgba(255, 255, 94, 0.1);   /* 暗黄 */
  --rainbow-4: rgba(94, 255, 158, 0.1);   /* 暗绿 */
  --rainbow-5: rgba(94, 158, 255, 0.15);  /* 暗蓝 */
  --rainbow-6: rgba(200, 94, 255, 0.15);  /* 暗紫 */
}
```

## 🖌️ 颜色使用规范与建议

### 1. 字体颜色规范
*   **绝对禁止使用纯黑 (`#000000`) 和纯白 (`#FFFFFF`) 作为正文颜色**。
*   浅色模式采用深灰蓝（`#1D1D1F`），深色模式采用浅灰白（`#F5F5F7`），能极大降低屏幕眩光，长时间阅读不累眼。

### 2. 毛玻璃（Glassmorphism）实现公式
卡片和导航栏必须包含以下三个属性，缺一不可：
```css
background: var(--card-bg);
backdrop-filter: blur(20px); /* 越大越有磨砂质感 */
border: 1px solid var(--card-border);
```

### 3. 彩虹极光背景（`.rainbow-bg`）配置
*   背景容器使用了 `filter: blur(120px);`。
*   通过 6 个绝对定位的 `.blob` 色块撑满屏幕，并设置 25 秒交替的缓慢漂浮动画（`@keyframes float`）。
*   **注意事项**：不要随意提高彩虹光晕的透明度。浅色模式保持在 `0.4` 左右，深色模式**必须降低至 `0.1 ~ 0.15`**，否则深色模式会变成“夜店迪斯科风”，严重刺眼且失去高级感。

### 4. 卡片悬停交互
*   默认状态：低调的柔和阴影 `var(--card-shadow)`。
*   悬停状态（Hover）：卡片上浮 `translateY(-4px)`，同时阴影加深，边框亮度提升（浅色模式改用 `rgba(91, 141, 239, 0.4)`，深色模式改用 `rgba(255, 255, 255, 0.2)`）。
