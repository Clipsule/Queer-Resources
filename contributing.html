workspace_premium 数据更新流程

本站资源数据维护在 GitHub 仓库的 docs/resources.md，是一份 Markdown 表格。完整流程：

  1. Fork 仓库并创建新分支：git checkout -b update/add-new-resource
  2. 编辑 resources.md，按照现有章节格式添加 / 修改行，保持表格格式一致
  3. 运行解析脚本，重新生成 resources.js：
    python3 scripts/parse_resources.py
  4. 提交并推送，发起 Pull Request：
    git add -A
git commit -m "docs(resources): 新增 XXX 资源"
git push

verified PR 审核标准

  • ✅ 资源链接实际可访问（合并前维护者会手动点测）
  • ✅ 资源属于当前分类 / 章节，或 PR 说明了重新分类的理由
  • ✅ 同一章节内，没有与现有条目的名称或 URL 重复
  • ✅ 说明文本不包含歧视性语言，不误导读者
  • ✅ 医疗或法律内容已加入「以官方最新说明为准」提醒
  • ✅ PR 描述清晰，写明「为什么要更新 / 新增 / 移除」

terminal 技术开发环境

本站是无构建步骤的纯静态站点，使用 Tailwind CDN，不需要安装 Node / npm，不需要打包。

Python 脚本： scripts/parse_resources.py 仅依赖 Python 3.7+ 标准库（re、pathlib、json）。

本地预览： 任意静态服务器即可：

python3 -m http.server 8080
# 访问 http://localhost:8080
